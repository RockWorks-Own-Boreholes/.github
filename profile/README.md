## Inside RockWorks

RockWorks is a local Windows geology app with a named rock desk, a short model list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside borehole data you already own and holds only the model that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra models wait for their own title. RockWorks starts with a local profile and does not need a complex account system.

The rock desk stays on a project you already keep. Untitled models stay off the live list.

## Quick Start with RockWorks

1. Open the last RockWorks session on borehole data you own, not a new empty model.
2. Read the rock desk and the last handoff.
3. Finish one visible section view inside RockWorks.
4. Write what changed, then close with a shorter model list than you found.
5. If the desk feels crowded, drop anything that belongs to a different project.
6. Leave the rock desk on data you already keep.
7. If a model is not yours, leave it off the live list.
